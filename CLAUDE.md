# CLAUDE.md

## Technical architecture

This project has the following apps:
 * `apps/backend` - backend application (Fastify)
 * `apps/web` - web frontend application (React SPA)

### Key points
 * `tRPC` for communication between backend and frontend
 * REST API for external SDKs and CLI clients
 * `Better Auth` for authentication, user management and session management
